🤖 Building an Autonomous Edge Vision Rover with Raspberry Pi & Python

💡
Build Log Summary: This project explores building a low-cost, fully autonomous ground vehicle capable of obstacle mapping, edge vision tracking, and failsafe navigation using Python and a Raspberry Pi.

1. System Architecture & Hardware Stack

Designing an edge-computed rover requires balancing compute throughput with power draw. We paired a Raspberry Pi Zero 2W running Raspberry Pi OS Lite with an L298N dual H-bridge motor controller and two 6V micro gear motors with optical encoders.

Subsystem Component Operating Voltage Interface
Compute Brain Raspberry Pi Zero 2W 5.1V @ 2.5A CSI Camera, GPIO, I2C
Motor Controller L298N Dual H-Bridge 7.4V - 12V PWM GPIO Signals
Telemetry Sensors HC-SR04 & MPU-6050 3.3V / 5.0V Trigger/Echo GPIO & I2C
Vision Unit Pi Camera Module 3 Wide 3.3V MIPI libcamera / OpenCV

2. Vision Pipeline: Real-Time Color Masking

Using OpenCV's optimized ARM build, we downscale the CSI video stream to 320x240 at 30 FPS. This leaves plenty of headroom for the PID controller running in the background to adjust wheel velocities.

import cv2
import numpy as np

def detect_target_vector(frame):
    # Convert BGR frame to HSV color space
    hsv = cv2.cvtColor(frame, cv2.COLOR_BGR2HSV)
    lower_bound = np.array([25, 80, 80])
    upper_bound = np.array([35, 255, 255])
    
    # Binary mask and contour detection
    mask = cv2.range(hsv, lower_bound, upper_bound)
    contours, _ = cv2.findContours(mask, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)
    
    if contours:
        largest = max(contours, key=cv2.contourArea)
        (x, y), radius = cv2.minEnclosingCircle(largest)
        if radius > 15:
            center_error = (x - (frame.shape[1] / 2)) / (frame.shape[1] / 2)
            return float(center_error)
    return None

3. Obstacle Avoidance & Reactive Steering

When ultrasonic sensor telemetry reports an obstacle within 20cm, the rover halts its vision tracking loop, executes an in-place turn away from the detected vector, and re-evaluates clearance before resuming navigation.
